# 小小骑士 · v0.2（原型）

像素风横版动作。**HTML + Canvas 2D，零依赖**，双击 `index.html` 即可运行（不需要服务器）。

- 基准分辨率 **480×270**，整数倍最近邻放大
- v0.1 的完整备份在 `_v1_基线/`（本次改动前复制）

---

## 运行

双击 `index.html` → 主菜单。

| 菜单 | 作用 |
|---|---|
| **开始** | 从最近一次存档开始（没有存档则新开第一关） |
| **存档** | 3 个存档位，读档进入对应进度（有存档时显示关卡与魔法石数量） |
| **训练** | 进入训练场：平地 + 五种魔法石 + 木桩 + 岩壁，随便练 |
| **放弃** | 退出到"旅程到此为止"界面 |

游戏中 `Esc` / `Tab` 打开暂停菜单：继续 / 保存进度 / 返回主菜单 / 放弃。

---

## 操作

| 键 | 作用 |
|---|---|
| `A` / `D` | 左右移动（双击 = 冲刺） |
| `空格` | 跳跃（空中再按 = 二段跳） |
| `Shift` | 闪避冲刺（不打断投矛/剑技蓄力） |
| `左键 长按` | 蓄力：持剑=剑技 / 持矛=投矛力度，松开出手 |
| `左键 长按 + W` | **元素附魔**：元素剑技 / 元素投矛；**光**会变成光刃 |
| `W` | 释放当前魔法石；选**风**时 = 位移（不打断蓄力） |
| `Q` | 切换武器：剑 / 长矛 |
| `S` | 收回投出的长矛（接住 → 空中跳跃 +1，下一跳带向前借力） |
| `滚轮` / `右键` | 切换魔法石 |

> 没有 HUD：当前魔法石是**头顶菱形符文**（冷却时变暗并走一圈进度环）。

## 六种元素

| 元素 | `W` 释放 | 剑技 | 备注 |
|---|---|---|---|
| **火** | 火球（落地爆炸） | 火焰半月斩 | |
| **雷** | 瞬发连锁闪电 | 电流半月斩 | 魔法石为**紫色** |
| **光** | 圣光柱 + 光爆 | **光刃**（见下） | |
| **冰** | 冰锥 | 冰晶半月斩 + **雪花粒子** | 命中地面留下 **1s 冰封路径** |
| **水** | 水球（抛物线） | **深蓝水刃** + 水珠 | 命中地面留下 **4s 水路径**；魔法石近乎黑色 |
| **风** | 位移 + **刷新一次空中跳跃** | **龙卷风**（见下） | 不能附着在长矛上；魔法石为绿色 |

> 每一种在蓄力时都会在**武器尖端（聚能点）**汇聚对应元素的粒子：火=火星、雷=电花、冰=雪花、水=水珠、光=光点。

### 风（按新文档重做）
- `W`：位移，之后**刷新一次空中跳跃次数**（和"收矛"同一套机制）
- 剑蓄力 + `W`：打出**向前移动的龙卷风** —— 只冲**一次冲刺的距离（约 53px）就原地定住**继续转，持续 **6 秒**
  - 沿途会被火球 / 水球 / **扎在地上的元素长矛** / 水路径**染色**
  - 火焰旋风 + 雷 → 大爆炸；水龙卷 + 雷 → 大范围麻痹；触发后旋风结束
- 持**长矛**蓄力时按 `W`：风不能附着在矛上 → 放普通风魔法（位移）

### 光刃（第三版，按新规则）
蓄力 3s / 7s / 12s 三段，从**聚能点往上生长**（不是光柱），最长 ≈ 二段跳极限高度（118px）：

| 蓄力 | 刃长 | 刃宽 |
|---|---|---|
| 3s（一段） | 1/3 | 1.0× |
| 7s（二段） | 2/3 | 1.2× |
| 12s（三段） | 满 | 1.5× |

- 剑形：**常数宽度的矩形剑身 + 顶部三角形剑尖**（不是锥形）
- 光粒子**沿整条剑身**被吸进去（不是只在剑尖聚一下）
- 蓄力时刀身外有**一圈圈环绕光环**在转（画在刀身下方，不挡光刃观感）
- 蓄力时**必须站在地面上**（空中无法起手光刃），且**不能移动**，每升一阶有一圈冲击 + 震屏
- 松开后**只能从竖直往鼠标那一侧劈**（-90° → 0° 或 -180°，固定 90°，不会绕一圈），下劈 0.10s
- 下劈带**挥砍曳影**（每一帧留一道残影，形成扇形刀路）
- 劈到**水平**瞬间：**黑闪冲击帧（黑屏 + 白色剑影/冲击环）+ 顿帧 0.13s + 震屏 + 横向冲击波**
- 随后**水平滞留 0.5s**：刃身保持水平持续发光冒粒，屏幕**一直轻微抖动**
- 滞留结束时**整条光刃直接爆散成光粒子**（最强烈震屏 16，抖到粒子散完）
- **从起手到光粒散完全程定身**：不能移动 / 跳跃 / 冲刺（`moveLock` = 0.5 + 0.85s）
- 低于 3s 松手 → 退化为普通光元素半月斩

### 长矛滞留元素
附魔长矛扎进地面/岩壁后**元素不会消失**：
- 持续冒对应元素粒子 + 氛围光 + 周期性脉冲环（冰是雪花粒子）
- 它是一处**持续的元素源**：在它旁边放雷/火/水会照常触发元素反应（比如火矛 + 雷 = 爆炸）
- 冰/水矛落地还会额外在地面留下对应路径
- 龙卷风经过它会被染色

### 元素反应（没有怪也能看到）
| 组合 | 表现 |
|---|---|
| 雷 + 火 | 范围大爆炸（冲击环 + 电弧 + 强烈闪光） |
| 火/水 + 风 | 火焰旋风 / 水龙卷（持续 1.6s） |
| 水 + 冰 | 冻结雾气 |
| 水 + 雷 | 沿水路径导电（连锁电弧） |

反应触发时会浮出一行小字提示。

## 关卡

- **第一关 · 夜森林**（剧情关）：森林平地 → 悬崖（必须收矛三段跳）→ 垂直岩壁（矛扎墙）→ 雷石 → 荆棘隧道（火烧）→ 墓园 → 光石
- **训练场**：一片平地，五种魔法石摆在出生点右边，中间有木桩，右侧有岩壁和三级台阶

## 目录

```
index.html                 入口（按依赖顺序引入所有脚本）
src/
  core/                    引擎层，与具体游戏无关
    util.js                基准分辨率 / 调色板 / 像素绘制原语 / 数学
    input.js               键鼠输入 → 480×270 坐标
    fx.js                  粒子 / 光爆 / 环 / 斩击弧 / 闪电 / 光柱 / 焦痕 / 灯源 / 震屏
  fx/
    elements.js            六种元素的定义与招式（火球/水球/冰锥/雷/龙卷风/光柱）
  world/
    world.js               World 主体：载入关卡 / 碰撞 / 检查点 / 烘焙调度 / 绘制
    terrain.js             地形烘焙 + 自然装饰（Object.assign 挂到 World）
    reactions.js           元素命中 / 滞留路径 / 元素反应（Object.assign 挂到 World）
    levels/
      level1.js            第一关 · 夜森林（纯数据）
      training.js          训练场（纯数据）
  entity/
    knight-sprite.js       骑士像素图 + 6 套姿态烘焙 + 描边
    player.js              移动 / 跳跃 / 冲刺 / 剑技 / 光刃状态机
    spear.js               投矛（扎地成平台 / 收矛刷新跳跃 / 滞留元素）
    enemy.js               怪物基类 + ENEMY_TYPES 注册表（预留）
    enemies/               具体怪物，一怪一个文件
  ui/
    menu.js                主菜单 / 暂停 / 存档面板
    hints.js               世界内教学文字
    hud.js                 HUD（预留）
  dev/
    selftest.js            ?test 自检（11 项）
    demo.js                ?demo=xxx 演示脚本
  main.js                  主循环 / 相机 / 光照 / 渲染管线
tools/                     像素图预览器
docs/STATUS.md             进度与交接
_v1_基线/                  v0.1 完整备份
_v2_第二版/                v1.1 完整备份（分层重构之前）
shots/                     验证截图
```

**加关 → `world/levels/level2.js`；加怪 → `entity/enemies/xxx.js`**（详见 `src/README.md`）。

|---|---|
| `?play` | 跳过菜单直接进第一关 |
| `?level=training&play` | 直接进训练场 |
