# STATUS · 小小骑士

更新时间：2026-11-15（v1.2 分层重构）

## 当前形态

纯前端 HTML5 Canvas 像素动作游戏原型。零依赖、零构建，`index.html` 双击即可跑。
基准分辨率 480×270，整数倍放大，`imageSmoothingEnabled=false`。
v0.1 完整备份：`_v1_基线/`。

## v0.3 本次改动

**元素表现**
- 冰剑技：冻结月牙 + **雪花粒子**（`D.snow` 十字雪花，FX 支持 `shape:'snow'`）
- 水剑技：**修好了"特效消失"**（`Magic.slash` 之前根本没有 ice/water 分支），现在是深蓝水刃 + 水珠
- 训练场补齐 **风魔法石（绿色）**，共六种
- 魔法石配色分离：新增 `EL.x.stone / stoneHi / stoneLo`，只影响石头与头顶符文，不影响招式
  - 雷 → 紫，水 → 近黑，冰 → 淡青，光 → 金，火 → 橙，风 → 绿
- 蓄力时**聚能点（武器尖端）**按元素汇聚粒子：火星 / 电花 / 雪花 / 水珠 / 光点（`chargeFocusFX`）

**光刃重做（第三版）**
- 从聚能点**往上长**，底部宽尖端收窄的刀形（不再是光柱），满蓄力 ≈ 118px ≈ 二段跳极限高度
- 三段蓄力：3s = 1/3 长；7s = 2/3 长 + 1.2 宽；12s = 满长 + 1.5 宽（`lightBladeGrowth`），每升阶一圈冲击 + 震屏
- **下劈方向修好**：`-90° → 0°` 或 `-90° → -180°`，固定 90°，不会再绕一圈
- 蓄力**必须站在地面**（空中不会生成光刃，退化为普通光斩），且**定身不能移动**
- 低于 3s 松手 → 普通光元素半月斩

## v0.4 风元素改动（按 14:48 更新的文档）

- `W` 位移之后**刷新一次空中跳跃**（`airBudget +1`，与收矛一致）
- **风不能附着长矛**：持矛蓄力时按 `W` → 普通风魔法（位移），不再走附魔
- **剑蓄力 + 风 → 向前移动的龙卷风**（`Magic.spawnTornado`）
  - 沿途吞掉火/水/冰弹或水路径 → **染色**成火焰旋风 / 水龙卷
  - 被雷击中：火旋风→大爆炸，水旋风→大范围麻痹，旋风结束
  - 撞墙或 2.0~2.9s 后消散
- 新增自检 `G_wind`：bud=2 / used=0 / vx=298 —— 三项行为都对

## v0.5 本次改动

- **龙卷风移动约束**：只向前冲 `PH.dashSpeed * PH.dashTime`（≈53px，一次冲刺的距离）后 `vx=0`
  原地定住继续旋转，**寿命 6s**
- **风环加密**：漏斗从 10 层加到 20 层，每层两圈错相位环 + 外圈暗边；形状改为**上大下小**（底部细、顶部张开）
- **长矛滞留元素**（实装）：
  - 附着元素的长矛扎住后持续冒元素粒子 / 氛围光 / 周期脉冲环（冰=雪花）
  - 长矛成为**持续元素源**：`World.react` 会把它算进反应源（测试 `H_stuckReact`：火矛 + 雷 → 爆炸 shake=9）
  - 冰/水矛落地额外留下对应路径
  - 龙卷风路过元素长矛会被染色
- 自检增至 9 项，全绿

## v0.6 光刃手感

- 下劈 0.18s → **0.10s**（更快）
- 新增 **hold 阶段**：劈到水平后刃身**滞留 0.68s**（持续发光/冒粒/冲击环），再 fade 消散
- **黑闪冲击帧补上**：`Game.setImpactFrame()` + 渲染层在闪黑之上叠**纯白剑影（矩形+三角尖）+ 同心冲击环**
- **震屏**：`FX.shake(13)`，并拆出 `FX.updateShake()` 让**顿帧期间屏幕照常抖动**（之前顿帧会把抖动冻住）
- 光粒子改为**沿整条剑身**被吸入（3 个/2 帧，随机落在刃身各处）
- 剑形重画：矩形剑身 + 三角剑尖（去掉了难看的锥形）

## v0.7 光刃表现

- **下劈曳影**：swing 阶段每帧记录一道残影（角度/长度），绘制时按寿命淡出，形成扇形刀路（最多 9 道）
- **水平滞留加长**：0.68s → **1.4s**
- **水平期间持续抖动**：hold 阶段每帧 `FX.shake(1.9)`，屏幕上一直有细微震动
- **结束爆散**：hold 结束调用 `lbBurst()` —— 沿整条刃喷 78 颗光粒 + 双 blast + 双环 + 全屏白闪 + `FX.shake(16)`，
  光刃本体立即消失；抖动衰减（6.5/s）≈0.7s，正好和粒子寿命（0.4~0.95s）一起散完
- 冲击帧顿帧 0.09 → **0.13s**

## v0.8 光刃后摇

- **顿帧保持 0.13s**（0.06s 反而太短，已改回）
- **水平滞留缩短**：1.4s → 0.85s → **0.5s**（抽成 `PH.lbHold`，一改全同步）
- **全程定身**：新增 `Player.moveLock`
  - 起手（swing）就锁 0.14s
  - 冲击后锁 `PH.lbHold(0.5s) + PH.lbAfter(0.85s 光粒消散)`
  - 定身期间：`vx=0`、跳跃/冲刺/蓄力/W 全部无效
  - 自检 `I_lock`：1 秒内位移 **0.0px**，锁结束后恢复移动
- 顿帧期间 `update` 不跑，`moveLock` 不会递减 → 在 swing 里补了保底值，避免顿帧把锁"吃掉"

## v1.1 光刃蓄力光环

- 蓄力时在刀身外画 5 圈**椭圆光环**，各自不同相位绕轴旋转（前半圈亮、后半圈暗）

- 每圈环上有一颗游走的高光点
